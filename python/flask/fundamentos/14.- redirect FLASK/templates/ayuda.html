Conceptos Clave de Redirección

1. ¿Qué es una solicitud POST?

Es un método HTTP diseñado para enviar datos al servidor dentro del cuerpo del mensaje (por ejemplo, al registrar un producto).

2. ¿Qué es una solicitud GET?

Es un método HTTP enfocado en solicitar o pedir un recurso al servidor (como renderizar una vista HTML). No altera el estado del servidor.

3. ¿Para qué sirve redirect()?

Le instruye al navegador del usuario que realice de manera inmediata una nueva petición independiente hacia una ruta URL distinta.

4. ¿Por qué request.form está vacío tras la redirección?

Porque request.form vive estrictamente dentro del ciclo de vida de la petición original (POST). Al invocar redirect(), se genera una segunda petición independiente (GET) que nace vacía.
